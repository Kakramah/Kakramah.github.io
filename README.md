# البوابة المركزية الموحدة لمشاريع خلدون عكرمة (Khaldoun Akramah Master Hub)

البوابة الرقمية الرسمية والواجهة الموحدة الشاملة لكافة الإنتاجات الوثائقية، الاستراتيجية، التراثية، والسيادية التي أنتجها خلدون عكرمة، والمستضافة على شبكة GitHub Pages المباشرة:
`https://kakramah.github.io/`

---

## المكونات والميزات

- **فهرس المشاريع التفاعلي:** تصفية فورية للمشاريع المنشورة بحسب مجالاتها (جيوسياسي وطاقة · تراث الساحل وجبلة · سيادي وطني · ذاكرة وعدالة).
- **محرك بحث مدمج:** وصول فوري لأي دراسة أو مشروع بالاسم أو الكلمة الدلالية.
- **بنك الأدوات والحزمة:** وصول مباشر لدستور مشاريع خلدون عكرمة (الإصدار 3.8)، والقيم المرجعية، وأدوات الفحص الآلي.
- **مركز التوثيق والتواصل:** نموذج تفاعلي متصل بـ Web3Forms لاستقبال مقترحات التوثيق والاستفسارات.
- **الخطوط المعتمدة:** `Cairo Bold` و `Tajawal Regular` تحت رخصة الخط المفتوح SIL Open Font License (OFL) مستضافة ذاتياً ومحلياً في `fonts/`.
- **الأصول السيادية:** شعار العقاب المعتمد والتوقيع الحصري `@𝓚𝓱𝓪𝓵𝓭𝓸𝓾𝓷𝓐𝓴𝓻𝓪𝓶𝓪𝓱`.
